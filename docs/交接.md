# 交接：接手这个项目要先知道的事

写给下一个 session。按顺序读，前三节是必读。

---

## 1. 三十秒上手

```bash
cd ~/Projects/crystal-quest
python3 tools/serve.py 8123 --lan     # 开发服务器（--lan 让手机也能连）
```

| 要做什么 | 怎么做 |
|---|---|
| 本机玩 | `http://localhost:8123/` |
| 手机玩（同 Wi-Fi） | `http://<本机 IP>:8123/` |
| **线上（任何网络）** | **https://maxwu1981.github.io/crystal-quest/** |
| 跑测试 | 浏览器开 `http://localhost:8123/tests/`，看「88/88 通过」（数字会随新测试长） |
| 数值模拟 | `http://localhost:8123/tests/?balance` |
| 模块体检 | `python3 tools/lint_modules.py`（**三项都要过**） |
| 改完发布 | `bash tools/deploy.sh`（已登录过，不会再要授权） |
| 调试模式 | 网址加 `?debug`：分页标题显示地图 id 与坐标，手机上多出「血 / 战」两个钮 |

**没有 Node。** python3 是 3.9。要跑 JS 用 macOS 自带的
`/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc -m`。

## 2. 用户是谁、他要什么

用户是**导演**，我是开发。他在两台电脑上开 Claude，手机上试玩。

**他反复强调过、绝不能忘的三件事：**

1. **不要一直告诉他怎么做，直接执行。** 他明说过「请执行啊不要我一直问」。
   凡是我能做的就做完再报，只有真正需要他拍板的才问（而且要给选择题 + 附图）。
2. **画面一律用 Gemini 生成，不要自己程序化画。** 原话「不管是迷宫的元素、
   还是地图的背景、还是战斗的背景，都请用 Gemini 来生成会比较美观」。
   例外是逐帧动画（魔法特效、召唤演出）——那是按时间画的，不是静态图。
3. **画面往《歧路旅人》HD-2D 靠。** 见 `docs/HD2D方案.md` / `HD2D评估.md`。

他最近下了一份**总监团队**的角色设定，列出四类硬性规定（全屏 UI、脱战清 Debuff、
自动补血、道路与特效分离）。前三条已落地，第四条还没做。

4. **改完要自己进游戏确认，并且要发布出去。** 2026-09-07 他为这条专门骂过一次：
   全屏改完、测试全绿、我在 localhost 上量到四边黑边都是 0，而他手机上一点变化都没有——
   因为三个提交**全躺在本地，一次都没 deploy**。他玩的是线上那份。
   完整的四步验收写进 CLAUDE.md 了（「验收：什么叫改好了」那一节），照着做。

### ~~① 三个物理职业一个技能都没有~~ ← 已做（2026-09-07），下面留着当验收单

三个物理职业各有三招，1 / 4 / 7 级各开一招，`data/skills.json` + 「战技」指令。
schema 与设计理由写进 CLAUDE.md 了，这里只留导演要拍板的两点：

**门槛选的是「冷却回合 + 少数几招收 HP」，没有加第二套货币。**
冷却存在战斗 actor 上，战斗结束就丢，进不了存档；HP 只有拼命（25%）与七星步（10%）收。
另一条路（限次）没选，理由是它在一场三回合的杂鱼战里等于无限。**这条随时可以换。**

| 职业 | 1 级 | 4 级 | 7 级 |
|---|---|---|---|
| 拳头师 | 连环拳（两段，缓 1） | **碎甲**（无视六成防御 + 破甲） | 拼命（放 25% 血，必中重击） |
| 家将 | **开脸**（挡煞：敌人先打他 + 防护） | 踏罡（全体） | **七星步**（八段） |
| 山猎人 | 屏息（必中 + 高会心） | 抹毒（附带中毒） | 扫山（全体） |

导演点名的破甲 / 嘲讽 / 多段斩三样都在里面（粗体那三招）。
顺带修了两件事：`statusPhase` 的状态倒计时改成照 `STATUS.turns` 泛化（原本是手写名单）；
自动战斗那边有一句无差别的「普攻反正打得死一只就别用战技」，会让家将从头到尾一招都不放。

**还没做的**：战技没有自己的演出，现在借的是普攻的刀光（`slash`/`swing`）。
按导演「画面用 Gemini」那条，逐帧特效属于例外（可以写代码画），
但这是**下一轮**的事——至少七星步与踏罡值得各有一套。

### ~~② 召唤的 MP 门槛太高~~ ← 已做（2026-09-08）

MP 22–60 → 10–28，自动战斗补上了整条請神分支。细节写进 CLAUDE.md 的 summons 那节。
两个值得记住的点：

**「一场只请得动一尊」有一半不是 MP 的锅，是吕布。** 他 `drain:'mp'` 放完 MP 归零，
而论单发伤害他永远排第一，所以 AI 每场第一手请他然后整场结束——实测 20/20 场都是他。
`pickSummon` 改成按「有效伤害 ÷ **真实代价**」排（drain 那位的真实代价是身上全部 MP）之后
才真的能请一轮。**只调数值不动这条，改了也白改。**

**`tests/balance.js` 现在有童乩路线与「请神」一栏。** 之前那张表里根本没人请过神，
改 summons.json 的数字前后跑出来一模一样，看着像「改动没影响」。
改召唤的数值前后一定要对这一栏（现在 Boss 战 1.3–1.9 尊，改之前是 0.95）。

### ~~③ 道路与特效分离~~ ← 已做（2026-09-08），但**根因不是交接单原本写的那个**

交接单原话：「我生成的物件瓦片每一张都自带一层地面，拼在一起就是几种地板打架」，
并说做这件事的 agent 中断了、一行没写。**两句都不对**——量过之后：

- 十张物件瓦片**早就是透明底了**（实心 24–41%、外圈实心 **0%**），一层地面都没自带；
- 合成管线也早就写好了（`terrain.js` 的 `OBJECT_GROUND` / `SEAMABLE`，
  按邻居决定铺哪种地，`seamTile` 还顺手烘了接地影）。

真正的根因是另一件事，量出来才看得见：**`stone_wall` 漏在 `CASTER` 表外**。
隘寮石城整整 351 格是它，而它和自家地板 `flagstone` 的明度差只有 **10.9/255**
（墙 85,92,94 / 地 105,101,97，ΔRGB 32/765）——本来就快分不出来了，
再加上漏登记 ＝ 墙脚一道影子都没有，整张图就读不出哪里是路。
（其余几张没这个问题：洞窟墙地差 27、古塚 67、室内 53。）
而且 `inert` 也是拿 `CASTER` 判的，所以漏登记的墙**还反过来接受地面那一套**：
崖影投到墙上、青苔裂缝长到墙面上。

补上 `stone_wall: 1` 与 `ore_vein: 1` 之后，实机量到墙脚的明暗落差 **13.6 → 37.4**。
`tests/cases/maps.js` 加了一条：每一种「挡路」的瓦片都必须登记成投影源，
或者明确属于三类例外之一（水/发光石、抠底合成那批、房子那套）。拿探针验过真会红。

**教训**：交接单上写的「根因」也要自己量一遍。这条如果照着做，
就是花一整轮 Gemini 去重出十张本来就没问题的瓦片。

## 4. 出图管线（Gemini）——这条最容易踩坑

**用内置浏览器 `mcp__Claude_Browser__*`，不要用 Claude in Chrome。**
用户同时在两台电脑上开 Claude，Chrome 会互相抢同一个 Gemini 会话。

开工顺序（**每一步都别跳**）：
1. **先刷新页面**。闲置超过一分钟就会出问题。
2. `eval(localStorage.getItem('cq'))` 恢复辅助函数（`__fill` / `__go` / `__ready` /
   `__imgs` / `__tile` / `__sheet` / `__grid` / `__shipStrip` / `__save`）。
3. 点两个开关：「上传和工具」→「制作图片」，再把「宽高比」设成 1:1。
   **浮层菜单在浏览器窗格隐藏时不会渲染**（Angular 的 `.cdk-overlay-pane` 要动画帧），
   点不动就先 `tabs_select` 把分页顶到前面；菜单项要从 `.cdk-overlay-pane` 里按文本找。
4. **卡住（一直显示 Creating your image）就刷新。**
   不要去猜额度或审核——我猜错过两次，绕去改写提示词、另开对话，全是白费。
   （唯一真的被内容挡下的是「石棺」：带 tomb / chest / lid 的提示词两次都被
   Gemini 自己标题成 Error 且回应为空，换成中性说法就出来了。）
5. 回传：`location.href='http://127.0.0.1:8124/px?m=1&f=<名字>.png&d='+encodeURIComponent(base64)`
   接收端是 `tools/art_receiver.py`（要先跑起来）。
   **文件名只能是字母数字下划线**，连字符会被拒。多张要拼成一条长图一次传
   （整屏 base64 会超过 URL 长度上限）。

## 5. 这个项目栽过的坑（每一条都真的发生过）

- **对象字面量后写的键会静默盖掉 `...展开`。** `effects.js` 曾经写成
  `{ ...SPELL_FX, …, fire, thunder }`，于是新写的多段式魔法演出**一次都没播过**，
  而测试全绿、控制台干净。`lint_modules.py` 的 C 项专查这个。
- **`replace()` 找不到目标会静默不改。** 我给 `render.js` 插落影函数时，
  锚点 `const GHOST = 0.42;` 早就被删了，结果只插了调用点、函数本体没进去。
  **每次 python replace 之后都要 grep 验证。**
- **模板串里的 CSS 写 `\21BB` 会被当成八进制转义**，整个模块 SyntaxError、游戏白屏，
  而测试和 lint 都看不见。测试「每个模块都 import 得动」就是为这个加的。
- **遇敌区没在 `ZONE_BG`/`MAP_BG` 登记 → 战斗背景静默退回通用**，
  地平线停在旧位置、人浮在天上，而地图、遇敌表、测试全都正常。
  隘寮石城与万金古塚就这么漏了一整轮。
- **`posterize()` 三通道独立取整会把近灰的东西染出色相**——(120,125,135) → (109,109,146)，
  整面城墙变蓝紫。要用 `posterize_luma`（只压明度）或 `snap_to_palette`。
  但**`posterize_luma` 也有缺陷**：它 r,g,b 同乘一个系数，会把彩度 max−min 一起放大
  （评估文档量过）。物件瓦片一律走 `snap_to_palette`。
- **`set_art.py` 会把非角色非怪物的母版当瓦片压成 16×16 逻辑。**
  背景图必须走 `is_bg()` 排除——当初 16 只怪就是这么全被压成方块的。
- **浏览器窗格隐藏时**：截图超时、Chrome 把定时器节流到 1 秒一次（等图的循环会卡死）、
  Angular 浮层不渲染。要看画面就把画布渲染一帧后回传本机：
  ```js
  const g=window.game; g.render(0,{fps:60});
  const cv=document.createElement('canvas'); cv.width=768; cv.height=672;
  const c=cv.getContext('2d'); c.imageSmoothingEnabled=false;
  c.drawImage(g.canvas,0,0,g.canvas.width,g.canvas.height,0,0,768,672);
  await fetch('http://127.0.0.1:8124/px?f=SHOT_x.png&d='+encodeURIComponent(cv.toDataURL('image/png').split(',')[1]));
  ```
  落在 `assets/art/`，**看完删掉**。
- **连续 `getImageData` 会让 Chrome 把画布降级成软件光栅**，帧耗时 2ms→60ms 且不会恢复。
  量性能要重开页面。
- **`git add -A` 会把正在跑的 agent 的半成品一起提交。** 派 agent 之前先划清文件归属，
  提交时只 add 自己动过的路径。

## 6. Agent 使用要点

用户明确要求**多 agent 并行**。但这个 session 里 **16 个 agent 有 6 个撞会话额度中断**，
其中 4 个零产出。经验：

- **每个 agent 独占一批文件**，任务描述里把「绝对不要碰」列清楚。
  几个 agent 同时改一个档一定互相盖掉。
- **浏览器分页也要分**：让每个 agent `tabs_create` 开自己的，
  否则它们会把彼此的分页导航走。
- 中断的 agent 常常已经做完大半（成果留在工作区），**先看 `git status` 再决定重派还是接手**。
- 额度重置时间会在错误信息里写（这次是 22:30 Asia/Saigon）。

## 8. 等导演拍板的事

0. **战技的门槛用「冷却 + 少量 HP」对不对**（见第 3 节 ①）。
   现在最贵的是拼命：25% 最大 HP 换一次必中重击，缓 4 回合。
   要更硬派可以把 HP 收得更狠、冷却拉更长；要更爽快就反过来。
1. **那 6 张生成好的迷宫接不接**（对应第三、七、八幕，而现在只有第一幕能玩）
2. **23 件 tier 6–10 装备**定义了却永远拿不到（显式列在测试白名单里）
3. **难度：全开箱 4 级就 100%**（根因 `def ≥ 60` 等于物理免疫，乌火攻击才 30）
4. **海底地图要不要做**（导演说飞船要能「在海中」，但做交通那位 agent 正面驳回了，
   理由见 `交通与世界移动.md`）
