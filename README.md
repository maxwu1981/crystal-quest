# 去屏東打怪

2D 回合制 RPG，背景设在台湾屏东六堆客家庄。纯 JavaScript + Canvas，无依赖、无构建。
一趟 1–2 小时的完整流程：内埔庄 → 六堆平原 → 罗经圈两层 → 大武山祭场 → 打倒「乌火」取回火种 → 结局字幕。

恒春的「出火」三百年没熄过，上个月熄了。老册子写那把火是先民留下来压山的。
火熄第三天起，庄里开始有人被魔神仔牵走。昌黎祠的庙祝把四个庄内后生仔叫来，让他们上山把火种带回来。

## 运行
ES Module 不能用 `file://` 直接打开，需要任意静态 HTTP 服务器：

```bash
python3 tools/serve.py
```
然后打开 <http://localhost:8123>（调试模式：<http://localhost:8123/?debug>）。
没有 python3 也可以用 `ruby -run -e httpd . -p 8123`，或 VS Code 的 Live Server 插件。

## 操作
| 键 | 作用 |
|---|---|
| 方向键 / WASD | 移动、选菜单 |
| Z / Enter / Space | 确认、和 NPC 说话、开宝箱（战斗中按住可加速） |

## 队伍与职业
初始四人：阿勇（拳头师）、巴冷（山猎人）、秀琴（青草婆）、文彬（符仔仙）。
拿到庙祝给的「六堆令旗」后可随时转职，共六种：

| 职业 | 特点 |
|---|---|
| 拳头师 | 武馆出身，挨得住也打得动 |
| 山猎人 | 脚程最快、回避最高 |
| 家将 | 空手一次挥两记，HP 最高 |
| 青草婆 | 治疗、防护、净化、复活 |
| 符仔仙 | 属性攻击与全体魔法 |
| 走贩 | 什么都会一点 |

## 系统
- 回合制指令战斗（设置里可切换 ATB），物理 / 属性魔法 / 全体魔法 / 会心 / 防御 / 逃跑
- 状态异常：中毒（战斗后持续，走路掉血）、睡眠、黑暗、防护；祛蚀散、明目露、醒神铃、净化、旅馆
  （黑暗与睡眠打完就散，所以明目露与醒神铃只在战斗中用得上，菜单里是灰的）
- 属性：火 / 冰 / 雷 / 暗 / 光。暗克山里的活物（山猪、芒神），阴的东西反过来抗暗；
  光克阴的东西（乌泥、好兄弟、水鬼、乌火）
- 装备三槽（武器 / 防具 / 饰品）；**武器与防具穿上后，走路和战斗都看得见**
  （饰品是戒指、护腕、靴子这类，32×48 的小人身上画不出来，只有数值没有外观）
- 材质分级按硬度排序：木 → 青铜 → 铁 → 钢 → 银 → 秘银 → 精金 → 陨铁 → 龙；防具分重甲与法袍两线
- 一趟只捡得到约 1400 金币，所以流程里走得完的是前四档：杂货铺卖木 / 青铜 / 铁那三档与全部消耗品，
  铺子后头「寄货的打铁师傅」那个架子卖钢这一档（钢剑、钢匕首、钢拳套、水晶杖、钢甲、符文袍）
  与疾风靴、秘银戒指；银以上（t6–t10）的装备已经备在 `data/items.json` 里，等宝箱铺开再进流程
- 23 件世界神话装备，各有专属效果：王者之剑（光属性）、草薙剑（雷）、冈格尼尔（必中）、
  干将莫邪（两连击）、金刚杵、埃癸斯、天之羽衣、衔尾蛇之环（免疫异常）等；
  其中 19 件武器防具有专属造型（4 件饰品同上，不画），商店永远不卖，
  全部散在宝箱、Boss 掉落与伯公坛的「寄付」里，一周目就能收齐
- 怪物取自台湾民俗与在地生物：魔神仔、山猪、好兄弟、虎头蜂、水鬼、芒神、食果蝠
- 步数制遇敌、马赛克转场、Web Audio 合成的音效与 BGM、开源像素字体

## 美术
角色 32×48、瓦片 32×32（逻辑坐标仍是 256×224，`src/core/draw.js` 的 `ART` 控制倍率）。
角色图由 Gemini 生成后经 `tools/` 里的管线处理成像素图；缺哪个方向就自动退回已有的方向。

```bash
python3 tools/import_downloads.py    # 把下载的原图处理并导入 assets/art/
python3 tools/reassign.py            # 按配色重新归位（改名后错乱时用）
python3 tools/recolor.py <职业 id>    # 换掉某个角色的配色
python3 tools/chestfit.py            # 体检宝箱位置（宝箱不可通行，放错会堵死通路）
python3 tools/chestfit.py cave_2 4   # 在某张图上挑 4 个合格的新宝箱位
python3 tools/proportion_check.py -v # 角色比例体检（同一个人各方向体型要一致）
python3 tools/proportion_check.py --sheet   # 导出站姿/迈步对照图给人眼审
python3 tools/match_tone.py A.png B.png     # 把 A 的配色对齐到 B（补生成单帧后用）
python3 tools/set_art.py             # 看当前精度与母版覆盖
python3 tools/set_art.py 4           # 从母版派生出 ART=4 的美术并改 draw.js
```

### 美术精度与母版
`src/core/draw.js` 的 `ART` 决定画布倍率（逻辑坐标恒为 256×224）：

| ART | 画布 | 角色 | 瓦片 |
|---|---|---|---|
| 2 | 512×448 | 32×48 | 32×32 |
| 4 | 1024×896 | 64×96 | 64×64 |
| 6 | 1536×1344 | 96×144 | 96×96 |
| 8 | 2048×1792 | 128×192 | 128×128 |

`assets/art/master/` 存的是 ART=8 精度的母版，`assets/art/` 是游戏实际加载的那一份，
由 `tools/set_art.py <ART>` 从母版缩下来。**出图一律先存母版**（回传时带 `m=1`），
否则以后想调精度只能一张一张重新生成——初版就是这么被卡住的。

处理流程：洋红抠底 → 只保留最大连通块 → 按身高归一化裁剪 → 面积平均缩小 → 色阶量化 → 描边。
导入后会自动体检身高一致性，偏差超过 12% 会报警。
